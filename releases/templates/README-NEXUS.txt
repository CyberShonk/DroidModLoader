Droid Mod Loader {version}

Install or update:
1. Extract {apk} from this ZIP.
2. Open the APK on your Android device and allow installation if Android asks.
3. To update an existing DML installation, install over it. Do not uninstall first;
   uninstalling can remove app data. Keep a backup of important data before updating.
4. Open Droid Mod Loader and follow the setup instructions.

This ZIP is an Android APK download, not a Vortex installer.
SHA256SUMS.txt lists checksums for the files in this ZIP.
LICENSE and THIRD-PARTY-NOTICES.txt contain the distribution licenses and notices.
