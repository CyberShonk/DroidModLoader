# Droid Mod Loader v0.8.0-beta

This release adds file selection during installation, supported RAR5 extraction, setup and storage information, recorded activity, and deployment diagnostics.

**Beta software: back up important game folders before testing.**

`2026-10-30`

### Known Issues

- Legacy archive cleanup is not automatic. Files are retained when originals cannot be verified or the copy is still needed by a source or library selection. ([`b8bc585`](https://github.com/CyberShonk/DroidModLoader/commit/b8bc5851e9556e3052b337b8b4622a2bd4d214b1))
- Game folder validation checks known executable and master file markers; game store layouts and runtime compatibility are not exhaustively qualified. ([`6129862`](https://github.com/CyberShonk/DroidModLoader/commit/61298620686f65306c3f9dbc564b1210ddae608c), [`6814fdc`](https://github.com/CyberShonk/DroidModLoader/commit/6814fdcff26cef81502e515020bd5f2f6a3c6262))
- RAR5 is limited to a 32 MiB declared dictionary, 4 MiB of metadata input, 8,200 metadata read calls, 4,096 entries and 64 path segments. Metadata byte limits can be reached before the entry limit with long paths. Links, unknown sizes, newer compression versions and service records other than a bounded stored quick open index are not supported. ([`70a5530`](https://github.com/CyberShonk/DroidModLoader/commit/70a55303d32498474b1f1100680a141ffbaf0e19))
- Password protected, encrypted and multipart RAR archives are not supported. ([`dc70fec`](https://github.com/CyberShonk/DroidModLoader/commit/dc70fece68f8e5daef06bdbe55d8a0379612827f))
- Some uncommon 7z compression or encryption variants may remain unsupported. ([`00c4de3`](https://github.com/CyberShonk/DroidModLoader/commit/00c4de3491d3448d08d7c584ad1a7e11895151df))
- Returning to a previous deployment target does not automatically verify every managed file against changes made outside DML. ([`2fdabec`](https://github.com/CyberShonk/DroidModLoader/commit/2fdabecdf4ca22f123525801815d077e9b1b6c4e))

## Upgrade Notes

- Back up important game folders before testing deployment features.
- Android 11 or newer is required.
- Install the release APK over the existing release app. Do not uninstall or clear app data first if you want to retain profiles and state managed by DML.
- Confirm the active profile and selected game folder before deploying. Use **Change Game Folder** in settings if the folder needs selecting again.
- Review Notifications and Recovery Details if DML reports unfinished work.
